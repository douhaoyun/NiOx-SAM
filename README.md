# NiOx-SAM

Code and analysis notebooks for:  
**"Division of labor in self-assembled monolayers enables rational interface engineering for high-performance inverted perovskite solar cells"**

## Contents
- `task1.py`, `task2.py`: core processing / analysis scripts
- `*_prompts_sam.py`, `*_qa*.py`: QA dataset generation / merging utilities
- `*.ipynb`: analysis / plotting notebooks (bindenergy, cbm, charge, descriptor, verify)

## Requirements
See `requirements.txt`. Typical environment: Python ≥3.8.
